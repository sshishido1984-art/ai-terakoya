# 生成AI寺子屋 (ai-terakoya)

臨床検査技師のための、生成AI活用の学び舎です。シーン別のプロンプトをコピーして、【 】を自分の言葉に置き換えるだけで、すぐに使えるプロンプト集を提供します。

## 公開サイト

https://sshishido1984-art.github.io/ai-terakoya/

## このサイトについて

生成AI（ChatGPT・Claude・Geminiなど）の基本的な知識から、臨床検査技師の実務で使えるプロンプトまでを1つのページにまとめたHTMLサイトです。

## 主なコンテンツ

- 生成AIとは？（得意なこと・苦手なこと・仕組み）
- 使い方（プロンプトの型、変数の置き換え方）
- プロンプト集（9カテゴリ：文書作成／学術・研究／学会発表・スライド／精度管理・データ解釈／教育・新人指導／院内コミュニケーション／業務効率化／学習・自己研鑽／メンタル・キャリア）
- 安全に使うための注意事項

## 使い方

1. プロンプト集からシーンに合うものを選ぶ
2. 【 】で示された変数を自分の状況に置き換える
3. 生成AI（ChatGPT・Claude・Geminiなど）に貼り付けて使う
4. 出力内容は必ず自分で確認し、必要に応じて追加で指示して仕上げる

## 注意事項

- 患者情報など個人を特定できる情報は、生成AIに入力しないでください
- 各施設の情報セキュリティ規程・利用ガイドラインを必ず確認してください
- 生成AIの出力は誤りを含む場合があるため、最終判断は必ず専門家自身が行ってください
